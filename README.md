# Harsh Chandegara – Fashion Portfolio

Customized from "The H Portfolio" template by Ameer Hamza (MIT licence, see LICENSE).

- `index.html` – the public portfolio
- `admin.html` – private admin page (opens at /admin)
- `portfolio.config.js` – default text
- `netlify/functions/api.mjs` – saves admin changes and uploads

No passwords are stored in this repository. The admin login is set in Netlify's environment settings.
